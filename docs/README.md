# Biofetch documentation

Read [architecture/resource-manifest-contract.md](architecture/resource-manifest-contract.md)
first. It is the current contract for downloader ownership, snapshot layout,
per-snapshot locks, aggregate manifests, paths, immutability, and release
validation.

`docs/refactor/` contains historical implementation plans, smoke notes, and
closeouts. They explain how the current code evolved but are not current
architecture. Documents explicitly marked superseded must not be used as the
active contract.

`docs/implementation-plan/` contains dated implementation roadmaps. A roadmap
marked superseded is retained only for decision history.
