# GO Annotation Dataset Discovery Implementation Plan

Version: v1.0
Date: 2026-06-16
Status: current

## Goal

Allow `biofetch go annotation fetch` to omit `--datasets` and interpret that
omission as "download every annotation dataset discoverable from the selected
GO annotation source for the selected formats".

The default `--formats` behavior stays unchanged: omitted `--formats` means
`gaf` only. A full all-format download remains explicit:

```bash
biofetch go annotation fetch --dir_out /data/go --formats gaf,gpad,gpi
```

## Current Contract

Current GO annotation fetch behavior builds URLs from user-supplied file stems:

```text
<base-url>/<dataset>.<format>.gz
```

Examples:

```text
goa_human.gaf.gz
mgi.gpad.gz
sgd.gpi.gz
```

`--datasets` currently means the `<dataset>` stem, not a filename or URL.
`--formats` currently supports `gaf`, `gpad`, and `gpi`.

## New Contract

When `--datasets` is provided:

- Preserve the current explicit behavior.
- Validate each value as a dataset stem.
- Build the full dataset-format cross product.

When `--datasets` is omitted:

- Resolve the GO annotation source as today.
- Resolve `--formats` as today.
- Fetch the annotation directory index from the source base URL.
- Parse links that match `<dataset>.<format>.gz`.
- Keep only links whose format is in the requested format set.
- Build assets from the discovered file links instead of constructing a blind
  dataset-format cross product.
- Deduplicate and sort discovered file names before download planning.
- Fail clearly if no matching files are found.

The manifest scope remains:

```text
datasets_formats = "<comma-sorted datasets>|<comma-sorted formats>"
```

## Implementation Steps

1. Add an index discovery path in `internal/geneontology/annotation.go`.
2. Keep explicit dataset validation in a separate helper so invalid explicit
   values fail before any download attempt.
3. Add a small HTML href scanner that extracts file basenames and reuses
   `parseAnnotationFileName`.
4. Update `validateAnnotationConfig` so omitted `--datasets` is accepted.
5. Update CLI help text and examples to show both auto-discovery and explicit
   dataset selection.
6. Add tests for:
   - omitted `--datasets` discovers all matching `gaf` datasets
   - requested formats filter the discovered files
   - no matching discovered files returns a clear error
   - explicit dataset behavior remains unchanged

## Acceptance

- `go test ./internal/geneontology` passes.
- `go test ./...` passes.
- `biofetch go annotation fetch --help` documents the omitted-datasets
  behavior.
- No changes are required for `lock` or `sync`; they already operate from
  local files or `manifest.lock`.
