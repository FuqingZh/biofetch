# Code of Conduct

This project follows the [Contributor Covenant Code of Conduct, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We expect respectful, constructive collaboration and do not tolerate
harassment, discrimination, or abusive behavior in project spaces. To report a
problem, contact the repository maintainer through a private GitHub security
advisory or direct GitHub message. Do not include secrets or licensed database
files in a report.
